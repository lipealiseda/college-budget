# College budget

4 year UF budget. Static site on GitHub Pages, no backend and no Airtable.

All numbers live in `data.json`. The page reads it from this repo, and anyone with the link can view.
Editing needs a fine grained GitHub token (this repo only, Contents read and write) pasted into the page on your own device. Every edit is saved as a commit, so the history of every change is in this repo.
